1. สร้างโฟลเดอร์เก็บไฟล์สำรอง
	mkdir C:\xampp\htdocs\kaduab_clientsdatabase\database\backups

2. สำรองฐานข้อมูล

กรณี MySQL user root ไม่มีรหัสผ่าน:
C:\xampp\mysql\bin\mysqldump.exe -u root --single-transaction --routines --triggers --events --default-character-set=utf8mb4 clientsdatabase > C:\xampp\htdocs\kaduab_clientsdatabase\database\backups\clientsdatabase_before_migration_2026-07-29.sql

---------------------------------------------------------------

กรณี root มีรหัสผ่าน ให้เพิ่ม -p:
C:\xampp\mysql\bin\mysqldump.exe -u root -p --single-transaction --routines --triggers --events --default-character-set=utf8mb4 clientsdatabase > C:\xampp\htdocs\kaduab_clientsdatabase\database\backups\clientsdatabase_before_migration_2026-07-29.sql
----------------------------------------------------------------

3. ตรวจสอบว่าไฟล์สำรองถูกสร้างแล้ว

dir C:\xampp\htdocs\kaduab_clientsdatabase\database\backups

ต้องเห็นไฟล์:
clientsdatabase_before_migration_2026-07-29.sql

---------------------------------------

จากนั้นจึงรัน Migration:
cd C:\xampp\htdocs\kaduab_clientsdatabase
php artisan migrate
php artisan optimize:clear
------------------------------------------------------

คำสั่งกู้คืนกรณีเกิดปัญหา
C:\xampp\mysql\bin\mysql.exe -u root clientsdatabase < C:\xampp\htdocs\kaduab_clientsdatabase\database\backups\clientsdatabase_before_migration_2026-07-29.sql
-----------------------------------

กรณีมีรหัสผ่าน:
C:\xampp\mysql\bin\mysql.exe -u root -p clientsdatabase < C:\xampp\htdocs\kaduab_clientsdatabase\database\backups\clientsdatabase_before_migration_2026-07-29.sql

ควรเก็บไฟล์ .sql นี้ไว้นอกโฟลเดอร์โปรเจกต์อีกหนึ่งชุด เช่น ไดรฟ์ D หรือแฟลชไดรฟ์ และไม่ควรอัปโหลดไฟล์สำรองขึ้น GitHub ครับ
